# mycelium-agent-mcp

> MCP (Model Context Protocol) client for the **mycelium** agent SDK: stdio and streamable HTTP; tools, resources and prompts.
>
> **mycelium** 的 MCP（Model Context Protocol）客户端适配：stdio 与 streamable HTTP；工具、资源与提示模板。
