# mycelium-agent-model

> Model provider SPI for the **mycelium** agent SDK: `ModelProvider` / `EmbeddingProvider` traits, requests, streaming deltas, embedding vectors and capability declaration.
>
> **mycelium** 模型提供方抽象（SPI）：`ModelProvider` / `EmbeddingProvider` trait、请求、流式增量、向量与能力声明。

- crates.io 包名：`mycelium-agent-model`；Rust 导入名：`mycelium_model`（`[lib] name` 固定，`use mycelium_model::…` 直接可用）
- 使用入口：请依赖门面 crate [`mycelium-agent`](https://crates.io/crates/mycelium-agent)
- 仓库与完整文档：<https://github.com/oxroot-crypto/mycelium>
- 许可证：[MIT](https://github.com/oxroot-crypto/mycelium/blob/main/LICENSE-MIT) OR [Apache-2.0](https://github.com/oxroot-crypto/mycelium/blob/main/LICENSE-APACHE)
