# mycelium-agent-tools

> Tool SPI and registry for the **mycelium** agent SDK: `Tool` trait, execution context, structured output and `#[tool]` macro re-export.
>
> **mycelium** 工具抽象（SPI）与注册表：`Tool` trait、执行上下文、结构化输出与 `#[tool]` 宏再导出。

- crates.io 包名：`mycelium-agent-tools`；Rust 导入名：`mycelium_tools`（`[lib] name` 固定，`use mycelium_tools::…` 直接可用）
- 使用入口：请依赖门面 crate [`mycelium-agent`](https://crates.io/crates/mycelium-agent)
- 仓库与完整文档：<https://github.com/oxroot-crypto/mycelium>
- 许可证：[MIT](https://github.com/oxroot-crypto/mycelium/blob/main/LICENSE-MIT) OR [Apache-2.0](https://github.com/oxroot-crypto/mycelium/blob/main/LICENSE-APACHE)

本 README 位于 crate 目录内，随 `cargo package` 一起发布；根 README（含双语说明与快速开始）见仓库首页。
