# mycelium-agent-core

> Domain kernel for the **mycelium** agent SDK: messages, tool protocol, events, run state machine, error taxonomy and configuration.
>
> **mycelium** agent SDK 的领域内核：消息、工具协议、事件、运行状态机、错误体系与配置。

- crates.io 包名：`mycelium-agent-core`；Rust 导入名：`mycelium_core`（`[lib] name` 固定，`use mycelium_core::…` 直接可用）
- 使用入口：请依赖门面 crate [`mycelium-agent`](https://crates.io/crates/mycelium-agent)
- 仓库与完整文档：<https://github.com/oxroot-crypto/mycelium>
- 许可证：[MIT](https://github.com/oxroot-crypto/mycelium/blob/main/LICENSE-MIT) OR [Apache-2.0](https://github.com/oxroot-crypto/mycelium/blob/main/LICENSE-APACHE)
